# About the project

- **Main focus**: Learn more about the connection between classes and the use of methods in Java.
- **What is the project?**: A complete chess game featuring a pawn promotion system and moves such as en passant and castling.
- **Where does the foundation come from?**: From Professor Nelio Alves Java course hosted on the Udemy platform, Section 23.
- **What was learned?**: More complex class relationships, optimized exception handling, use of a UI class for color presentation, improved structure for execution within the command prompt (CMD) environment, and new features such as screen clearing.
